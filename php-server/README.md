# Kiffy на обычном PHP-хостинге (без Node.js, Python и баз данных)

Работает на любом shared-хостинге с PHP 7.4+. Хранение — JSON-файлы с flock,
доставка — HTTP long-polling. Веб-приложение `app.html` **само определяет**
транспорт: если WebSocket недоступен, оно пробует `api.php` и переключается
на long-polling (виджет «Сервер» покажет бейдж `POLL`).

## Установка

1. Загрузите в `public_html` (или в подпапку):
   - `api.php`
   - `index.html`, `app.html`, `android.html`
   - папку `data/` (внутри уже есть `.htaccess`, запрещающий доступ извне)
2. Права: папка `data/` должна быть записываемой (обычно 755/775 достаточно).
3. Админ-вход: откройте `api.php` и задайте
   `const KIFFY_ADMIN_PASSWORD = 'ваш-пароль';`
   Пустое значение = вход под именем `admin` отключён.
4. Откройте `https://ваш-домен/app.html` — подключение произойдёт автоматически
   (сервер подставится из адреса страницы).

## nginx

Если хостинг на nginx, закройте `data/` отдельно:

```nginx
location ~ ^/data/ { deny all; return 404; }
```

## Отличия от Python/Rust-сервера

| | Python/Rust | PHP-хостинг |
|---|---|---|
| Транспорт | WebSocket (мгновенно) | long-polling (до ~0.5 с задержки) |
| Шифрование PSK | да (--psk) | нет — используйте HTTPS хостинга |
| История | в RAM | `data/events.jsonl` (ротация >1 МБ) |
| `/setemoji`, IP-бан | да | нет (бан по имени) |

Команды, звёзды, глобальные сообщения, ЛС, якорь, typing — как в v2.

## Проверено

- `php -l` в CI (синтаксис).
- Поведение на конкретном хостинге может зависеть от ограничений
  `max_execution_time` — при проблемах уменьшите `LONGPOLL_SECONDS`.
