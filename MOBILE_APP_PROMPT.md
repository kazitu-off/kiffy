# Промпт для ИИ: нативное мобильное приложение Kiffy (Material You)

Этот файл — готовое задание для любой ИИ (Claude, ChatGPT, Gemini и т.д.),
чтобы она создала нативное приложение Kiffy для телефона. Скопируйте текст
ниже целиком в ИИ и прикладывайте этот файл как спецификацию протокола.

Веб-приложение `app.html` уже адаптивно и отлично работает на телефоне —
этот промпт нужен, если хочется **нативное** приложение.

---

## Промпт (копировать отсюда)

Создай нативное Android-приложение «Kiffy» на **Kotlin + Jetpack Compose +
Material 3 (Material You)** для чата с собственным сервером. Приложение
минималистичное, без рекламы, полностью на Material You: динамические цвета
(Monet), тёмная/светлая тема из системной, тон-палитры, скругления 12–28dp,
state layers, navigation bar, FAB.

### Точка входа в сеть

Сервер слушает ОДИН порт (по умолчанию 8888) и раздаёт три транспорта:

1. **WebSocket** `ws://<host>:<port>/ws` — рекомендуемый для мобильного
   приложения (мгновенная доставка).
2. **TCP** — 4-байтовый big-endian префикс длины + UTF-8 JSON (используется
   терминальным клиентом; можно не реализовывать).
3. **HTTP** — статика (не нужна приложению).

Подключение: `WebSocket` → первое сообщение от сервера `{"t":"hi","psk":false}`
(открытый режим) или `{"t":"nonce","nonce":"<hex>"}` (шифрованный PSK-режим).

### Рукопожатие

Клиент отправляет:
```json
{"t":"hello","v":2,"user":"имя","proof":"<hex или null>","pw":"пароль админа или null"}
```
- `user`: 3–20 символов, латиница/цифры/`_`.
- PSK-режим: `proof = HMAC-SHA256(пароль, nonce)` в hex. Ключ сессии
  (Fernet, 32 байта) = `SHA-256(пароль + "|" + nonce)`. После `hello` ВСЕ
  кадры в обе стороны — Fernet-токены (base64url), как у python-библиотеки
  `cryptography`: `0x80 || IV(16) || AES-128-CBC(PKCS7) || HMAC-SHA256(key[0:16],
  0x80||IV||CT)`; ключ шифрования — `key[16:32]`. Реализуй через WebCrypto-аналоги
  (на Android: `javax.crypto` AES/CBC/PKCS5Padding + Mac HmacSHA256).
- Имя `admin` требует пароль: если сервер ответил `{"t":"pw"}`, отправь
  `{"t":"auth","pw":"..."}`.

Ответы сервера: `{"t":"welcome",...}` / `{"t":"error","msg":"..."}`.

### Сообщения протокола (поле "t")

От клиента: `msg{text}`, `pm{to,text}`, `anchor{to}`, `unanchor`,
`users`, `typing{on}`, `ping{ts}`, `exit`.
Слэш-команды сервер тоже понимает внутри `msg.text`:
`/users /s [user] [msg] /anchor [user] /unanchor /help /exit`
и админские: `/star /unstar /global /setemoji /makeadmin /removeadmin /ban /unban /banlist`.

От сервера:
- `welcome{user,admin,users:[{n,s,a}],history:[...],psk}` — history — последние
  30 событий; отрисуй их, затем живой поток.
- `msg{from,text,ts,star}`, `pm{from,text,ts}`, `pm_sent{to}`,
  `global{from,text,ts}`, `sys{text,ts}`, `error{msg}`,
  `users{users:[{n,s,a}]}` (s — звезда, a — админ),
  `typing{user,on}`, `pong{ts}`.

### Экраны

1. **Чат** — top app bar «Kiffy» + бейдж онлайна; список сообщений:
   свои — заполненные контейнеры справа, чужие — слева с аватаром-инициалами
   (цвет из хэша имени), ЛС — с иконкой замка, `global` — бейдж GLOBAL,
   `sys` — по центру мелко. Индикатор «X печатает…». Ввод: outlined text
   field + FAB-кнопка отправки. Чип «→ имя» при режиме ЛС/якоря.
2. **Люди** — список онлайна: аватар, имя, бейджи (⭐ звезда, 🛡 админ),
   действия: написать (PM), закрепить (anchor).
3. **Виджеты** — cards: «Сейчас онлайн» (чипы-аватары, тап → ЛС), «Сервер»
   (адрес, бейдж шифрования plain/PSK, живая задержка через `ping{ts}`→`pong`
   каждые 5 с), «Действия» (тема, копировать адрес, объявление для админа),
   «О приложении».
4. **Диалог подключения** — сервер (по умолчанию последний использованный),
   имя, пароль админа (виден при имени admin), PSK-пароль (опционально).

### Поведение

- Переподключение с экспоненциальной задержкой 1→30 с, статус-точка
  (серый/жёлтый/зелёный), snackbar о потере связи.
- Набор текста → `typing{on}` не чаще 1 раза в 2 с; отправка/очистка → `typing{off}`.
- Введённое «Enter» отправляет. Длина текста ≤ 16000 символов.
- Хранить только адрес и имя (не пароли!) в SharedPreferences/DataStore.
- Иконка приложения: зелёный пузырь чата (Material Symbols `chat`).
- Языки интерфейса: ru + en.

### Референс-реализация

Вся серверная логика и протокол описаны в репозитории:
`kiffy_server.py` (эталон, asyncio), `rust/src/main.rs` (то же на Rust),
`app.html` (та же логика UI на JS, включая Fernet через WebCrypto —
удобный источник для портирования), `test_kiffy.py` (ожидаемое поведение
протокола). Дизайн — см. `app.html`: токены Material You в `<style>`.

Собери всё в один модуль Gradle, минимум зависимостей
(compose-bom, material3, okhttp для WebSocket или Ktor client).
Kotlin-код снабди unit-тестами на парсинг протокола и Fernet-раундтрип
(вектор для проверки: python `cryptography` даёт совместимые токены).
